# Afterlight

A browser-based, first-person exploration game set in a procedurally generated neon city. Find the three glowing relay beacons and restore the district grid.

## Run

Open `index.html` directly in a modern desktop browser. No server, build step, or extra project files are needed. Keep an internet connection available so the page can load Three.js and the optional fonts.

Select **Enter the city** to play. Click the game view if the pointer is released.

## Controls

- **W A S D** — move
- **Mouse** — look around
- **Shift** — sprint
- **Space** — jump
- **1 / 2** — select akimbo pistols / throwing knife
- **Q** — draw or holster the selected weapon (holstered weapons preserve concealment)
- **Left mouse button** — fire the akimbo pistols
- **Right mouse button** — throw the explosive knife (a miss takes 8 seconds to recover)
- **R** — reload
- **E** — restore a relay when nearby
- **Escape** — pause or resume

Each pistol hit drops a character. A knife that hits a hostile detonates and can disable nearby drones. Civilians flee when a weapon is drawn. Hostiles patrol and scan their surroundings, then pursue when they see you; holstering reduces their view distance. Red markers on the minimap are hostile drones; pale markers are pedestrians; **H** marks Helix Tower. Complete the relay and street security objectives to open the tower door, clear the two guards inside, then use the console at the center of the ground floor with **E** to breach it.
